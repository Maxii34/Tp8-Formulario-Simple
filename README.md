## Formulario Simple
# ⚙ Descripción

Este proyecto consiste en una aplicación web desarrollada con React que incluye un formulario simple.
Permite ingresar Nombre, Apellido, DNI y Email. Al enviar el formulario, se valida que todos los campos estén completos y se muestran alertas utilizando SweetAlert2 para notificar éxito o error.
---

# 🛠 Tecnologías utilizadas

- React
- React Bootstrap
- React Hook Form
- SweetAlert2
